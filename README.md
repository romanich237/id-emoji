# Emoji ID

Каталог Telegram Premium Emoji для поиска и копирования идентификаторов эмодзи.

**Сайт:** https://emoji.romanich237.dev

## Возможности

- Поиск Premium Emoji по обычному эмодзи (❤️, 🔥, 👍).
- Просмотр наборов и добавление своего по ссылке `t.me/addemoji/...`.
- Копирование ID, HTML `<tg-emoji>` и кода для Telegram-ботов.
- Избранное, экспорт JSON и поддержка WebP, WebM, TGS.
- Кэширование в браузере для экономии запросов к API.

## Как пользоваться

Открой сайт, вставь обычный эмодзи в поиск или выбери набор. Нажми на нужный эмодзи, чтобы скопировать его ID или код.

**API:** https://id-emoji-api.kupulluyc1242.workers.dev/api/packs
