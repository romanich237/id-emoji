# Emoji ID

Визуальный каталог Telegram Premium Emoji с поиском по ID и символу, отображением наборов и копированием кодов для Telegram-ботов.

Сайт: https://romanich237.github.io/id-emoji/

## Возможности

- Просмотр эмодзи из выбранных Telegram-наборов.
- Добавление набора по ссылке `t.me/addemoji/...` в рамках текущей сессии.
- Поиск по ID, символу, названию набора и небольшому словарю синонимов.
- Просмотр WebP, WebM и TGS (для TGS необходима поддержка браузером распаковки gzip).
- Копирование ID, HTML-тега `<tg-emoji>` и поля `icon_custom_emoji_id`.
- Локальное избранное и экспорт каталога в JSON.
- Публичный API для получения паков и эмодзи.

Каталог работает через Telegram Bot API. Расширенный семантический поиск, автоматический сбор всех популярных паков и MCP-сервер пока не реализованы.

## Идеи и вдохновение

При проектировании использованы **идеи возможностей**, представленных в следующих открытых проектах. Их исходный код, графические материалы и базы данных в Emoji ID **не копировались**.

| Проект | Что вдохновило |
| --- | --- |
| [tg-emoji-hub — TGlimmer](https://github.com/TGlimmer/tg-emoji-hub) | Каталог наборов, поиск, форматы копирования, JSON API и перспектива MCP |
| [premium-telegram-emoji — Zulut30](https://github.com/Zulut30/premium-telegram-emoji) | Визуальный выбор эмодзи и идея подбора для интерфейсов |
| [Tg-emoji-vault — sellble](https://github.com/sellble/Tg-emoji-vault) | Описание внешнего вида эмодзи и поиск для ИИ (в планах) |
| [telegram-premium-emojis — abbosahmad](https://github.com/abbosahmad/telegram-premium-emojis) | Сканирование паков и готовая разметка для ботов |
| [telegram-emoji-downloader — bohd4nx](https://github.com/bohd4nx/telegram-emoji-downloader) | Работа с WebP, TGS, WebM и конвертация файлов (полная конвертация в планах) |
| [telegram-emoji-skills — xdshkaaa](https://github.com/xdshkaaa/telegram-emoji-skills) | Представление ID и HTML в формате, удобном ИИ-агентам (экспорт навыков в планах) |

На момент проверки файлы лицензии MIT подтверждены в репозиториях **tg-emoji-hub** и **telegram-premium-emojis**. Для остальных перечисленных проектов отдельный файл лицензии не удалось подтвердить; поэтому их исходники не использовались. Ссылка на репозиторий не означает разрешение копировать его код или ресурсы.
