# Emoji ID

Визуальный каталог Telegram Premium Emoji. Выберите один из четырёх наборов, нажмите на эмодзи и скопируйте ID или HTML-разметку для Telegram Bot API.

Наборы: TgAndroidIcons, NewsEmoji, IconsInTg, tgiosicons.

Сайт: https://romanich237.github.io/id-emoji/

Источником изображений служит Telegram API. Для анимированных TGS требуется отдельный браузерный проигрыватель; пока отображается резервный символ.
